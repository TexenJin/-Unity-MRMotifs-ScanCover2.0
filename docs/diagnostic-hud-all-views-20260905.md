# 全档常驻诊断 HUD（2026-09-05）

## 本次改动

- 不再创建旧 Reject Acquisition Reticle：中央黄色方框、顶部大号黄色阶段计数一起隐藏。已有实例也停用；FPS/GPU 曲线及其数值不变。
- 下方 HUD 改为固定双栏：左侧接力、覆盖、成熟等待、冻结交叉、审计账与口径；右侧错位特征、转角、时序/位姿、融合写入、冻修、采集与封包。顶部保留当前显示档和真实生产路径。
- AuditRelay 的调度条件从壳可见改为正在采集，仍受非冻结快照、单次回读和 0.5 秒节流约束。所有显示档，包括合流仅纸，使用同一套生产提交缓冲诊断。
- 切档不再重置采集时钟；重复 SetAcquiring(true) 不重置时钟，暂停后恢复才重置。
- 隐藏时维护壳层年龄，但 Renderer 保持隐藏。纸皮审计保留逐块生产准入 RequestedVisible，不受总显示开关影响。
- 审计显示等待首批、采样中、暂停保留、等待深度、更新滞后，以及最近有效回读距今秒数。融合统计明确为独立回读，不暗示与接力同批。

## 口径与边界

- 全批统计，不是中央方框或肉眼缺口位置的局部统计。
- 每段“齐”以本段命中为分母；后两段只接收前段对齐样本，不能当作全场覆盖率。
- 残为均值/峰值毫米；无样本不代表通过。相关特征不等于因果定罪。
- 未改变融合写入、冻结阈值、生产准入、蒙皮密度或旧探针权限。5→10 cm 自适应现状保留。

## 验证

- Tools/TestDiagnosticHudViews.ps1 从实际 C# 提取调度表达式和状态方法，覆盖 48 种显示/采集/冻结/回读/时钟组合，并检查固定分区、旧控件停用、隐藏层显示和年龄更新接线。
- 使用 Unity 6000.3.9f1 自带 Roslyn、工程 Android 引用编译 C#；这不是完整 APK 或 Vulkan/设备验收。
- 上机检查：黄框/顶部黄字消失，性能曲线保留；在合流仅纸静看仍有接力回读与融合统计，来回切档栏目不变、采样继续；暂停时明确保留；双栏无截断。
- 全档运行接力审计会在原先未审计的档位增加约 2Hz 的诊断工作。实际可读字号、画面占用和帧率需 Quest 验证，未声称已完成。
