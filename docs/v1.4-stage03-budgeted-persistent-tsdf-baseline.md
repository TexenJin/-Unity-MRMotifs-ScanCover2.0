# v1.4 Stage 03 — Budgeted Persistent TSDF Baseline

This release freezes the Quest-tested Stage 03 baseline after the production
path moved from full-scene rebuilds to persistent, incremental TSDF fusion and
result publication.

## Frozen achievements

- Budgeted persistent fusion queue with early per-voxel representative
  selection and bounded aggregate evidence.
- Saturated voxels continue to accept conservative TSDF updates instead of
  becoming permanently frozen.
- Stable projective ownership and conservative free-space carving remain
  isolated behind the independent fast-decision shadow.
- Incremental authoritative block extraction with persistent per-block result
  ledgers and chunk publication.
- Yellow structural and green complex foreground presentation; orange and
  other diagnostic classes remain backend-only.
- Stable-plane registry bootstrap is now part of the incremental path, so
  disabling the expensive full-rebuild fallback no longer leaves RESULT empty.
- Candidate planes can participate in cold-start provisional semantics while
  repeated observations are still required for mature structural promotion.
- MC33 topology handling, feature-preserving optimization, Quest-style display
  remeshing, and persistent complex leases are included in the frozen source.
- Low-overhead performance summaries expose fusion/rebuild slice time,
  bootstrap time, semantic phases, persistent chunks, and result composition.

## Quest validation snapshot

The first three complete 12-frame batches after the bootstrap fix showed:

- batch 1: expected empty cold start while plane tracks were first observed;
- batch 2: 2,672 foreground triangles across 74 active result chunks;
- batch 3: 2,761 foreground triangles across 90 active result chunks;
- stable-plane bootstrap cost: 3.9–6.8 ms;
- post-cold-start fusion maximum slice: 6.3–8.8 ms;
- no production full-rebuild fallback.

The one-time fusion cold start is accepted for this baseline. The remaining
performance target is the 50–55 ms maximum incremental rebuild slice observed
in mature rounds, especially work inside relaxed semantic audit and other
still-monolithic finalization steps.

## Validation

- Unity 6000.3.9f1 C# compilation completed successfully.
- Existing project warnings remain; no new compile errors were introduced.
- Performance captures used fixed 12-frame batches with zero raw-frame
  timeouts.

## Scope note

The independent fast-decision shadow is intentionally paused during the
low-overhead production performance capture, so this release does not treat
those performance summaries as fresh missing-edge/extra-edge promotion proof.
The persistent production result is frozen; the independent path remains an
optimization and shadow-validation track.
